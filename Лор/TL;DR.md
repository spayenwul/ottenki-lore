# TL;DR — Лор

> Фундамент мира: 46 файлов от первичной космической дуальности до военной экономики.

## Уникальное
- **[[Творец и Разрушитель]]** — первичная дуальность; Разрушитель совершил Жертву, запечатав часть себя, чтобы Творение могло существовать
- **[[Бездна]]** — запечатанная часть Разрушителя, обретшая самосознание через осколки Белиала ([[Принцы Тьмы]]). Двойной контур печати: первичный (Владыки Демонов) + второй ([[НПС/Лиан|Лиан]])
- **[[Халдеи]]** — мёртвая туманность творения, родной мир Лиан, уничтоженный её же функцией («магнит для душ» → «пожиратель всех душ» без триггера)
- **[[Фобос и Деймос]]** — двойные солнца; **Деймос поглощён** при вознесении Ксвима → Фобос нестабилен, магический баланс сломан, пророчество о конце света считается сбывшимся
- **[[Теневая Завеса]]** — пассивная эманация Лиан. Замкнулась в [[Ночь тёмного знамения|1900 г.]], изгнав всех демонов; **пала ~2 месяца назад**. До 1900 г. Завесы как барьера НЕ было — изолировал только [[Теневой барьер Углеаса|барьер Углеаса]]
- **Пояс Астероидов** — физическое проявление всех разумных душ; Бездушные не имеют астероида. **★ Астероид = привязь, а не отражение:** Пояс держит души против тяги Лиан. Есть механика воздействия (Звёздный Сток) и пять ограничителей, включая гнев Души Земли
- **[[Небесная Астрология]]** — точная наука чтения Пояса: реестр рождений/смертей, поиск астероида конкретного лица, каталог аномалий; реагенты из фауны степей
- **[[Бездушные]]** — раса без души и астероида (создана [[Персонажи/Демоны/Демон Отражений|Терр'Карром]]) **и** отдельный современный феномен: ~200 живых тел без душ у башни Агнейра. Связь между ними не установлена
- **[[Поле Праха]]** (Пепельные Поля) — место гибели 50 000 Бездушных; единственный уцелевший источник о Демоне Отражений (записи Эрика Пустого, прочитанные из пепла)
- **Энергия Творения** — утечка из тюрьмы [[НПС/Лиан|Лиан]], источник всей магии и жизни
- **Император Варал** — перерожденец из другого мира, помнивший демоническое право; создал [[Логус Варалис]]
- **Великая Двойная Империя** (1521–1900) — эпоха сосуществования с демонами, закончилась [[Ночь тёмного знамения|Ночью Тёмного Знамения]] (вскрытие барьера Углеаса → замыкание Завесы → мгновенное изгнание всех демонов). ⚠️ [[Война тёмного знамения]] (12 лет после) — почти не написана
- **Великая Гора** — единственное крупное месторождение металлов, нервная система [[Душа Земли|Души Земли]]
- **5 Божественных Зверей** — созданы [[Серафиэль]], каждый хранит душу близкого ей человека. Свои файлы: [[Сервелос, Стремительная Тень|Сервелос]] (друг детства, олень — **исчез** после падения Тостада), [[Даскарин, Тихие Глубины|Даскарин]] (возлюбленный, кит — хранит тело богини), [[Литон, Нежный Колосс|Литон]] (брат, каменный волк — **его вой разносит металлы по миру**), [[Толубра, Змея Превращения|Толубра]] (сестра, змея — спит, шевельнулась), [[Зефирель, Шёпот Шторма|Зефирель]] (наставница, птица — улетела на восток). Состояние всех пяти читается из [[Пояс Астероидов|Пояса]]
- **Серебряная Чума** (1281–1283) — ~580k погибших; сформировала санитарные протоколы мира
- **Золотое Древо** — редкое дерево-аккумулятор, основа валюты «золотой листок»

## Подпапки
- **[[Лор/Экономика/TL;DR|Экономика (папка)]]** — все экономические материалы в одном месте: демоническая модель доменов (6 слоёв + калькулятор цен), прайс [[Экономика доменов]], смертные экономики ([[Экономика Земли Под Поясом]], [[Экономика мира]]), [[Экономика душ]], [[Военная экономика]]
