# Империя Ареан — Ветка Элизабет: Феникс из Пепла

> Массштабная геополитическая арка: восстановление Империи Ареан через Трёхфазный план Элизабет («Феникс из Пепла»), гражданская война в Хакирии, Вторая Врата, война с Углеасом.
