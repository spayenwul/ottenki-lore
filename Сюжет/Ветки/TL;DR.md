# TL;DR: Сюжет/Ветки

> Единый навигатор по 5 основным сюжетным веткам кампании в общем формате. Каждая ветка привязана к таймлайну (День 0 = Игра 00, ~50–60 дней). Персонажи-участники имеют таблицы участия в своих карточках.

## Уникальное

- **Единый формат** для всех веток: метаданные → участники → таймлайн → фазы → точки решений → открытые вопросы → ресурсы → перекрёстные ссылки → GM-only
- **Таймлайн** общий для всех: День 0 = Игра 00, ключевые якоря: Игра 34 (ритуал), Игра 40 (гибель Врат), Игра 45 (начало Шабаша), Игра 51 (Ночь 2)
- **3 нити**: А (Агнейр), Б (Эрр'Кин), В (Близняшки) + общая (Дракх/Кассиан/Громгайр)
- **Domain-time**: разное время в разных доменах/мирах (Провал, Рахат Маар, Мир Лэй Цзы)
