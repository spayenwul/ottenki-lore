# Формат ветки сюжета (единый стандарт)

> Используется для всех веток в папке `Сюжет/Ветки/`. Каждая ветка — отдельный файл. Если ветка одна и целостна — не дробить.

---

## Структура файла

```markdown
---
aliases:
  - Название ветки (короткое)
  - Альтернативные названия
tags:
  - область: [Рахат Маар / Кария / Ареан / Элзия / Персональная]
  - статус: [активна / завершена / на паузе / планируется]
  - нить: [А / Б / В / общая]  # А=Агнейр, Б=Эрр'Кин, В=близняшки
---

# Название ветки

> Однострочная суть: что происходит, зачем, каков масштаб.

## Метаданные ветки

| Поле | Значение |
|---|---|
| **ID ветки** | `BR-XXX` (уникальный идентификатор) |
| **Область** | Рахат Маар / Кария / Империя Ареан / Элзия / Персональная |
| **Нит(и)** | А / Б / В / общая |
| **Статус** | активна / завершена / на паузе / планируется |
| **Приоритет** | критично / высокий / средний / низкий |
| **Начало (День от Дня 0)** | День XX (или диапазон) |
| **Текущий конец (День от Дня 0)** | День YY / «в процессе» |
| **Мировая дата (ИК/ОПЖ)** | 480 ИК / 2001 ОПЖ + сезон/день |
| **Ключевой файл-источник** | Ссылка на основной файл события/сессии |

| Персонаж | Участие | Даты (День от Дня 0) | Роль в ветке | Последствия для персонажа | Статус |

## Таймлайн ветки (ключевые события)

| День от Дня 0 | Игра | Событие | Нить | Участники | Исход / Заметки |
|---|---|---|---|---|---|
| ДД | XX | Название события | А/Б/В | список | результат |
