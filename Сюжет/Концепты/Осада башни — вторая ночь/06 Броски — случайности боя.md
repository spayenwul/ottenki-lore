# Броски на случайности (честные, d100)

> Кидать по порядку — результаты ранних бросков дают модификаторы поздним (цепочка отмечена «→ мод»). Бэнды скошены под реальный расклад: круг 6 доминирует, оборона держит/тянет, Юстиниана — уравнитель, но новорождённая. Два главных контеста можно кидать встречно (оба d100 + мод, выше — побеждает) — это самый честный вариант; иначе одиночный d100 по бэндам ниже.

## Порядок
Сетап (купол) → Р1: мина · свора · база · тыл · скорость Забвения → Р2: контест богини · заморозка · удар по якорю → Плата.

---

## СЕТАП — успевает ли купол Вольфрамового стража
Формация встаёт не мгновенно; её охват к началу Р1.
```
1-15   едва ядро: малый радиус, много кто снаружи → Забвение бьёт шире
16-70  ядро+ключевые (Агнейр, Алдуин, Зинайда, Юди, дух) под куполом; периферия (дальние бесы, Шаррисс) снаружи
71-100 широкий купол: Шаррисс и часть бесов тоже под защитой
```
→ мод: если Шаррисс СНАРУЖИ купола — **−20** к броску «свора» (Забвение колеблет его контроль).

## РАУНД 1

### Р1-1 · Мина по Тенелому (наводит чувство башни Агнейра)
```
1-20    поздно/мимо — Тенелом всплывает чисто внутри, сразу ищет брешь
21-65   частичный бурст — оглушён ненадолго, остаётся в строю
66-100  прямое накрытие — тяжело оглушён, выбит из Р1
```

### Р1-2 · Шаррисс vs Пастырь за свору (контест Контроля)
Встречно: `Шаррисс 1d100` vs `Пастырь 1d100` (оба круг 5, равны). Либо одиночный (успех Шаррисса), **−20 если он вне купола**:
```
1-25    свору не отжать — массовка в полном составе на стенах
26-70   половина своры рассеяна/обращена
71-100  бо́льшая часть массовки обращена против атакующих
```

### Р1-3 · Линия у базы: Стужень vs Зинайда+Алдуин
Цель защиты — НЕ пустить к основанию (убить круг 6 нельзя). **+10 если гаубица била по Стуженю в этот раунд.**
```
1-30    Раскол проходит по основанию — пробоина, Агнейр (слит с камнем) ловит отдачу; база вскрывается → мод −15 ко всем броскам Р2
31-70   держат, но Зинайду отбрасывает, Сжатие на исходе; база цела, линия просела
71-100  чистый блок — Стужень не продвинулся
```

### Р1-4 · Тихоступ vs Валентин в тылу (контест; Пророк vs сокрытие)
**−15 если Забвение достигло ≥II (см. Р1-5) — дар Валентина сбоит.**
```
1-25    Тихоступ проскользнул к мягкой цели → под-бросок «кого» + «выживает ли»
26-65   размен: Валентин перехватил, но ранен (ВЫН 150) → бросок амулета
66-100  чистый перехват — Тихоступ отбит, Валентин цел
```
Под-бросок цели (если 1-25): `1-50` дух у гаубицы · `51-100` Розаден (теряем шпионов-наводку).
Тихая Жатва летальна для не-бойца → цель гибнет, **если не сработает амулет** (амулет только у Валентина; дух/Розаден — без страховки).

### Р1-5 · Скорость Холода Забвения
```
1-25    медленно — к концу Р1 только стадия I (тепловизоры ещё работают, дар Валентина цел)
26-80   стадия II (базовый): тепловизоры слепнут, периферия вне купола плывёт
81-100  рывок к III на периферии — вне купола почти выведены из строя
```

## РАУНД 2 — Юстиниана

### Р2-1 · ГЛАВНЫЙ: Юстиниана vs Безымень — контест за тьму
Богиня (выше круга 6), но новорождённая, против вкопавшегося круг-6-якоря.
Встречно (рекоменд.): `Юстиниана 1d100+30` vs `Безымень 1d100`. Либо одиночный (успех Юстинианы):
```
1-20    Безымень упирается — окно НЕ открывается → провальная ветка (Р3 / эвакуация в Рахат-Маар)
21-70   контест — Забвение замирает на текущей стадии, окно УЗКОЕ (на 1 заход)
71-100  доминирует — Забвение подавлено, часть мелких теней переходит к ней, окно ШИРОКОЕ → мод +15 к Р2-3
```

### Р2-2 · Заморозка Стуженя — хватает ли на заход
```
1-30    срывается раньше — возвращается и давит на ударную связку → мод −20 к Р2-3
31-100  держится достаточно — связка работает без Стуженя
```

### Р2-3 · Удар по Безыменю (исполнение связки)
Алдуин (Песчинка) + Зинайда (пролом) + Шаррисс (обращённая свора) + Юстиниана (держит волю).
Моды: **+15 широкое окно (Р2-1); −20 Стужень сорвался (Р2-2); −15 база вскрыта (Р1-3)**.
```
1-25    заслон теней держит — связка отбита, обряд цел, тяжёлый размен (бросок потери бойца) → бой в Р3
26-65   обряд сорван (оглушение/рана) — Безымень уходит вниз, Холод гаснет за 2-4 раунда
66-100  Безымень убит — Холод схлопывается резко, тени в развале, отступают вниз
```

## ПЛАТА (после исхода)

### Амулет Валентина (если триггерился в Р1-4)
```
1-100  амулет спасения (4 круг, разовый) гасит один летальный → Валентин жив, но амулет сгорел
```
(Без амулета у духа/Розадена страховки нет — гибель по Р1-4.)

### Потери расчётов (бесы на пулемётах)
Зависит от стадии Забвения (Р1-5) и того, были ли вне купола:
```
1-40    минимальные — 0-1 точка выбита
41-80   умеренные — 2-3 точки молчат к Р2 (слепые/мёрзлые)
81-100  тяжёлые — пулемётный огонь почти выключен к Р2
```

### Алдуин — Песчинка Времени
Не бросок: фиксированная цена **год жизни** за активацию (в Р2-3). Если активировал дважды — два года.

## Подкрепление из пустыни (опц. рычаг — если мастер вводит)
Прибытие через портал Рахат-Маара.
```
1-50    не успевает к Р2 (приходит к развязке/после)
51-100  входит в Р2 → мод +15 к Р2-3 (доп. бойцы на заслон/связку)
```

---

## Как читать исход (логика hold/fall)
- **Удержание** наиболее вероятно, если: купол ≥ядро (Сетап 16+), база цела (Р1-3 31+), Юстиниана открыла окно (Р2-1 21+), удар прошёл (Р2-3 26+).
- **Провал/эвакуация** копится, если: купол едва встал + база вскрыта (Р1-3 1-30) + Безымень устоял (Р2-1 1-20 ИЛИ Р2-3 1-25). Тогда — портал в Рахат-Маар, как в первую ночь.
- Цена удержания почти всегда ненулевая: бесы, вероятно Валентин (амулет), год(а) Алдуина, измотаны Зинайда/наёмники.
