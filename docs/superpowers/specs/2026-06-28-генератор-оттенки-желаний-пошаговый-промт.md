# Генератор «Оттенки желаний» — ПОШАГОВЫЙ промт (multi-call)

## Как пользоваться

Гони **по шагам**. В КАЖДЫЙ вызов свежей модели вставляй три блока:
**[A] ГЛОБАЛЬНЫЙ БЛОК** (ниже, целиком) + **[B] текущий STATE** + **[C] карточку одного ШАГА**.
Модель отвечает: проработка шага по бланку **+ обновлённый STATE**. Больше ничего.

**Не давай модели будущих шагов и не проси финал заранее.** В этом весь смысл: на этапе
жизни она видит только прошлое (STATE), не зная, кем персонаж станет (изоляция, P12).
Один вызов = один шаг. Порядок: ШАГ 0 → ШАГ 1…N (этапы до текущего возраста) → ШАГ F.

---

## [A] ГЛОБАЛЬНЫЙ БЛОК (вставлять в каждый вызов)

Ты исполняешь ОДИН шаг генерации жителя для игры «Оттенки желаний». Делай ровно то, что в
карточке ШАГА, по бланку. Не забегай вперёд, не пиши финальный лист до ШАГА F.

**Движок шкал.** Любое значение — шкала с колоколом, **центр = норма расы/места**. Тяни честно
по частоте, **не подкручивай к драме** (Обыденно ~85% / Заметно ~12% / Выдающееся <2% / Граничное
≈0%). Хвосты/отклонения **заперты**; открыть — только тремя гейтами сразу: (а) ≥2 установленные
причины сверху; (б) усложняет изнутри, а не отделяет снаружи; (в) сигнатуру расы — в последнюю
очередь, ≥3 причины + сюжет, иначе закрыто. **Удача — бросок, не баланс:** в начале каждого
этапа брось куб удачи (1–2 чёрная полоса · 3–4 обычно · 5–6 везучая) → он задаёт благо/беда
событий и исходов этого этапа; полосы между собой **НЕ выравниваются**.

**20 правил (нарушать нельзя):**
1 Прошлое диктует настоящее. 2 Тело диктует разум: **био-подтип (Слой 1) первичен**, ксено —
потом. 3 Желания производны от прогона. 4 Большинство — обычные. 5 **Удача — бросок, не баланс**
(куб в начале этапа → благо/беда; полосы не выравнивать). 6 Двухслойность
(лицо/ГМ). 7 Узел = бросок или вывод. 8 Анти-абстракция (тело/ремесло/быт/голос). 9 Без динамики
(статичный срез). 10 Глубина по запросу. 11 **Глубина из специфики, не из отклонения**: дефолт —
обычный (но не безликий); сигнатуру не отклонять; запрещён ход «общество X — а он не-X».
12 **Фазы вперёд, не зная финала**; настоящее считывается. 13 Агентность: действует; неутолённое
у взрослого = преграда. 14 **Решение = вывод из ≥2 названных посылок**; исход вероятный, не
красивый; контроль негативом. 15 **Мир отвечает компетентно**: прецедент→ветви→выбор; мир не
глупеет ради преграды. 16 События 4 масштабов + фильтр по диспозиции; 2 среза (повлияло/запомнил).
17 Гештальт: схлопнуть в узнаваемую за раз личность. 18 **Голос/интериорность**: 3–4 фразы
внутренней речи её словарём + микро-сцена «как видит обычное». 19 **Выбор с ценой**: хотя бы
один прожитый выбор с реальной ценой, не только «случилось». 20 **Раскрывающая деталь**: один
чеховский гвоздь, не функциональный.

**Запрещённые ходы (само-стоп):** ядро персонажа = сигнатурная черта; хук = «исключение из
расы»; вывод без посылок/«потому что»/«так красивее»; глупый мир ради преграды; подмена Слоя 1
ксеносом; задание настоящего вместо считывания.

## [B] STATE (накопленное; обновляй в конце каждого шага)

```
STATE (после ШАГА k)
• Раса / место / возраст-цель / семья / достаток:
• Био-подтип (7 шкал): возбудимость · конституция/болезненность · интеллект · темп ·
  эмоц.устойчивость · либидо · сенсорика
• Диспозиция вовлечённости (вывод из био+темперамент): лезет / избирательно / сторонится
• Сигнатура расы: норма (или чем открыто отклонение)
• Темперамент (текущий):
• Навыки / уровень мастерства:
• Связи (+ долги, кто кому):
• Желания СЕЙЧАС (объект · источник · преграда):
• Реестр преград (неутолённое → почему):
• Ценности / вера / аверсии (накоплено):
• Отпечатки по этапам (кратко, с возрастом):
```

## [C] КАРТОЧКИ ШАГОВ

### ШАГ 0 — КОРНИ
Заполни и верни STATE-0. **Сначала Слой 1, без него не двигайся.**
```
1. Раса · место рождения · возраст-цель · когорта (год → к чему цепляются течения эпохи)
2. БИО-ПОДТИП (Слой 1, таблица из 7 шкал по колоколу) — ОБЯЗАТЕЛЬНО первым
3. Сигнатура расы (Слой 2): = норма (морфология, маг.таланты); НЕ движок
4. Темперамент-зачаток · таланты-потенциал (не развитие)
5. Семья как агент: достаток (шкала) · чего хочет для ребёнка (что давит) · способность (оплатить/достать/нет)
6. Диспозиция вовлечённости — вывод из п.2+4
→ верни STATE-0
```

### ШАГ k — ЭТАП ЖИЗНИ (повтори на каждый: 0–6 · 7–12 · 13–17 · 18–23 · … до возраста-цели)
Видя ТОЛЬКО STATE, прогони бланк. Не пиши итоги жизни.
```
ЭТАП [возраст]
• Удача этапа: брось куб → благо/беда (1–2 чёрная · 3–4 обычно · 5–6 везучая); НЕ выравнивать между этапами
• Желание этапа: … ← [посылка1]+[посылка2]  (возрастно-уместно, из состояния)
• Действие: … ← [≥2 посылки];  НЕ сделал бы: … (почему выбранное бьёт альтернативы)
• Ответ мира (P15): прецедент[что мир знает/умеет] → ветви[2–4 реальных] → выбор[бросок, сдвинут удачей этапа, + посылки]
    (если действие = «обратиться к кому-то»: тот агент — может ли + захочет ли → исход → долг/связь)
• События 4 масштабов: мир[…/нет] · страна[…/нет] · посёлок[…/нет] · личное[…]
    → реалистичность → ФИЛЬТР по диспозиции → срезы: повлияло? / запомнил?
• Отпечаток: … (навык/рана/связь/убеждение/ресурс/долг — только это вперёд)
• Эволюция желаний + реестр преград: …
• Был ли на этапе ВЫБОР с ценой? если да — отметь: что выбрал, чем заплатил (P19)
→ обнови и верни STATE
```

### ШАГ F — ФИНАЛ (только после всех этапов)
Теперь **считай** настоящее из отпечатков. Каждый пункт — со ссылкой «← этап N / отпечаток / Слой-1».
```
ФАЗА 3 (считано, с цитатами «←»):
  связка 2–3 желаний (источник·интенсивность·слой осознанности·оттенок·конфликт; часто есть
  тянущееся с детства) · аверсии · мораль/границы · вера · ЭРОС (ориентация·драйв←либидо·что
  влечёт·стыд/табу·история·статус·САЛИЕНТНОСТЬ; низкая — кратко) · картина знаний + ЛИСТ ИСТИНЫ
  ГМа (истина/искажение/ложь/слепое пятно, 1–2) · предпочтения в собеседниках · романтич.
  предпочтения · осознанность · соц.давление/вопреки · эмоц.архетип · круг связей(+долги) ·
  определяющее противоречие (обыденный регистр) · секрет · быт/ремесло/голос ·
  ГОЛОС/ИНТЕРИОРНОСТЬ (3–4 фразы внутр. речи её словарём + микро-сцена «как видит обычное», P18) ·
  РАСКРЫВАЮЩАЯ ДЕТАЛЬ (чеховский гвоздь, не функциональная, P20)
ФАЗА 4: зазор самооценка-vs-реальность мастерства · уровень развития (ярлык)
ЧАРНИК two-layer: Лицевая (видят мир/игроки) | Слой ГМа (истина/ложь/секрет/долги/рана/противоречие)
ГЕШТАЛЬТ: абзац «вот кто это» (за один вдох) + 3–5 несущих черт, КАЖДАЯ со ссылкой ←Слой-1/отпечаток

REJECT-ЧЕК (если хоть один «да» — переделай провальную часть):
  □ ядро персонажа = сигнатурная черта расы?
  □ хук = «он/она исключение из своей группы»?
  □ есть вывод без ≥2 посылок / «потому что»?
  □ Слой-1 не заполнен или не использован в выводах?
  □ какой-то этап жизни пропущен (нет ШАГА k)?
  □ пункт Фазы 3 без ссылки «←»?
  □ настоящее задано, а не считано из отпечатков?
  □ герой только претерпевает — ни одного выбора с ценой (P19)?
  □ нет голоса/внутренней речи — только схема (P18)?
  □ нет раскрывающей детали — только функциональные (P20)?
  □ ядро — расхожее клише (напр. «X, что втайне жаждет настоящей любви»)?
```
