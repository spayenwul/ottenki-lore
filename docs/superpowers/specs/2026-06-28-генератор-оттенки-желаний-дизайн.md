# Генератор персонажей «Оттенки желаний» — дизайн модели

## 1. Назначение и область

Модель **последовательной генерации персонажей** (lifepath-типа), где каждый узел
ограничивает следующий, а итог — **полноценный человек**, а не набор статов.

- Делается под ролевую игру **«Оттенки желаний»** (фокус: *куда приводят желания и
  в чём их многогранность*), но **движок переносим** на другие проекты.
- Семейство-прецедент: Traveller / Burning Wheel (leads-гейтинг) / **Central Casting**
  (книга таблиц биографии) / Pendragon (черты-пары, страсти).
- **Форма на этом этапе — документ** (узлы + логика связей). Реализацию
  (ИИ-промпт или софт YAML+Python в стиле уже существующей тег-системы мира)
  выбираем после того, как логика устоится.

## 2. Принципы дизайна

| # | Принцип | Следствие для модели |
|---|---|---|
| P1 | **Прошлое диктует настоящее** (режим A) | Фазы 3–4 почти целиком — *выводы* из биографии, а не отдельные броски. |
| P2 | **Тело диктует разум** | Биология — корневой движок Фазы 1, раздаёт модификаторы на темперамент и желания. |
| P3 | **Желание — позвоночник** | Желания *производны* от биографии; подсистема желаний — центр модели. |
| P4 | **Статистика обыденности** | Каждый узел тянется по колоколу (центр = обычное) × модификаторы сверху. Большинство людей — обыкновенные; граничное редко и заслуженно. |
| P5 | **Удача — бросок, не баланс** | Удача НЕ самобалансируется (такого механизма нет). В начале каждой фазы/этапа — **бросок удачи**, задающий соотношение благо/беда событий и исходов этого этапа. Полосы реально неравномерны: бывают везучие и чёрные. См. §4.6. |
| P6 | **Двухслойность** | У персонажа есть лицевая сторона (видят мир/игроки) и сторона ГМа (истина, ложь, секреты, истинные желания). |
| P7 | **Узел = бросок или вывод** | Явно различаем входные узлы (катятся/гейтятся) и производные (считаются сверху). |
| P8 | **Анти-абстракция** | На выходе — тело/ремесло/быт/голос, а не воплощённая идея (анти-нейрослоп). |
| P9 | **Без динамики** | Генератор даёт *статичный срез*. Движение желаний во времени решает ГМ вживую (см. §13 Вне области). |
| P10 | **Ручка глубины** | Статист / НПС / ключевой — разный объём прогона (см. §11). |
| P11 | **Глубина из специфики, не из отклонения** | Дефолт — обычный человек *в пределах нормы* расы+места. «Норма» ≠ безликий средний: люди разнятся, но разброс **бытовой**, а не аномальный — «средний по всем осям» провал такой же, как эджи-изгой. Отличительность — из уникального пересечения обычных частностей × давления нормального мира на универсальные чувства, **не** из отклонения сигнатурной черты. Отклонения заперты гейтами (§4). |
| P12 | **Прожитые фазы, не ретроспектива** | Каждый возрастной этап генерится *вперёд и изолированно* — оператор на этапе N видит только состояние из этапов <N, **не зная финала**. Ни одна фаза не существует «чтобы объяснить настоящее». «Настоящее» (Фаза 3) **считывается** из накопленного, а не задаётся. См. §5 «Метод». |
| P13 | **Агентность** | На каждом этапе у персонажа свои возрастные желания, и он **действует** — мир отвечает (успех/частично/отказ + *причина*). Любое неутолённое желание у взрослого требует **конкретной преграды** (цена, страх, долг, нехватка средств, барьер); «просто не пробовал» допустимо только для ребёнка. См. реестр преград §5. |
| P14 | **Решение = вывод из посылок** | Любое желание/действие/исход **выводится** из явно названных посылок текущего состояния (биология · темперамент · ценности · прожитый опыт с возрастом · окружение · ситуация) и **показывается** как вывод («из A+B+C → D»). Берётся исход, который посылки делают **наиболее вероятным**, а не самый красивый/жанровый. Посылки — только **уже установленные** (вспоминаются, не выдумываются под решение). Нет ≥2 заземлённых посылок → решения нет. Контроль негативом: чего он **не** сделал бы и почему выбранное бьёт альтернативы. Запрещено: «потому что», «так красивее», жанровый рефлекс. |
| P15 | **Мир отвечает компетентно и из своей полноты** | «Ответ мира» — такой же вывод, как решение персонажа, но из состояния МИРА: история и институты (что народ/школа реально знает, умеет, помнит; **были ли прецеденты — почти всегда были**), компетентность и интересы отвечающих лиц **по их установленному уровню**, доступные им ходы. **Мир не глупеет ради преграды.** Бросок выбирает, какая из реалистичных ветвей сработала, — а не «тупит ли мир». |
| P16 | **Событийность и фильтр по диспозиции** | На каждом этапе проверяются события 4 масштабов (мир · страна · поселение · личное) — сначала **реалистичность их существования**, потом **задело ли**. Из био-подтипа+темперамента выводится **вовлечённость**: «лезет везде» → жизнь насыщенна; «сторонится» → событие проходит как факт, отпечатка нет. Два среза: фактически повлияло / отрефлексировано-запомнено (могут расходиться). Записываем по приоритету реального влияния + носимой памяти. |
| P17 | **Гештальт** | Прогон обязан схлопнуться в **узнаваемую за один раз личность**: абзац «вот кто это» + 3–5 несущих черт. Не формулируется кратко — персонаж не сложился, вернись и доведи. |
| P18 | **Голос/интериорность** | Для НПС/ключевых финал даёт **сознание, а не только схему**: 3–4 фразы внутренней речи её словарём + 1 микро-сцена «как она видит обычное». |
| P19 | **Выбор с ценой** | У ключевого персонажа — хотя бы один **прожитый выбор с реальной ценой** (а не только «случилось с ней»), иначе выходит жертва обстоятельств, а не личность. |
| P20 | **Раскрывающая деталь** | Одна **не-функциональная, раскрывающая** деталь, привязанная к ядру (чеховский гвоздь), не просто бытовая. |

## 3. Архитектура: ядро + плагин мира

- **Ядро (переносимое):** типы узлов, логика связей (входы→выходы), движок
  распределения (§4), подсистемы желаний (§6) и знаний (§7), правила деривации (§8),
  схема выходного чарника (§10).
- **Плагин мира «Земля-под-поясом»:** контент-таблицы, подставляемые в слоты узлов —
  расы (`Персонажи/Расы/`), локации (`Локации/`, Геополитика), фракции, магия,
  «течения эпохи» (`История и мифология`), сословия.
- Связь узлов наследует идею тег-системы мира (`tags_registry`): у узлов есть
  **синергии и конфликты**, движок проверяет совместимость.

## 4. Движок распределения: шкалы с наследуемыми гейтами

Каждый узел — это **шкала** (рандомизированный параметр), а не свободный выбор. У шкалы
есть распределение, и **доступ к её краям/отклонениям заперт порогами-гейтами, которые
открываются только значениями родительских узлов**. Гейты наследуются вниз по графу
зависимостей: значение A открывает гейты на B, значение B — на C. Это превращает «колокол»
из совета в механический замок и реализует P11 (отклонение нельзя получить даром).

### 4.1. Анатомия шкалы

```
шкала {
  ось:        напр. феромонное излучение [глухое ← норма → яркое]
  база:       колокол, центр = НОРМА расы/места; хвосты по умолчанию ≈ 0 (заперты)
  родители:   какие узлы сверху её модулируют
  гейты:      [ условие на родительские параметры → эффект на распределение ]
}
итог = бросок по базе, переразвешенной ТОЛЬКО открытыми гейтами
```

Если ни один гейт не открыт → бросок идёт по **обычному разбросу колокола** (живой
обычный человек, не клон — Обыденно/Заметно варьируют). Заперты только **хвосты-отклонения**,
пока их не отопрёт стэк причин сверху.

Тиры базового колокола (кривая вроде 3d6):

| Тир | ~Частота при закрытых гейтах | Пример (талант) |
|---|---|---|
| Обыденно | ~85–95% | как все |
| Заметно | ~5–12% | способный |
| Выдающееся | <2%, **только если открыт гейт** | одарённый |
| Граничное | ≈0%, **только если открыт стэк гейтов** | уникум |

### 4.2. Три гейта на любое отклонение (замок P11)

Чтобы шкала ушла из нормы, отклонение должно пройти **все три**:

1. **Каузальный гейт** — отклонение есть конец стэка из **≥2 конкретных причин** в
   родительских узлах. Бесхозных хвостов нет (нельзя «просто бросить» уникума).
2. **Гейт глубины (анти-контраст)** — «черта усложняет персонажа *изнутри* или лишь
   отделяет его от группы *снаружи*?» Если только отделяет — **отказ**.
3. **Сигнатурный замок** — расовая подпись (феромоны у Люциканов, спячка у Айни и т.п.) —
   *последнее*, что вообще можно трогать: требует **≥3** наследуемых причин + явного
   сюжетного основания. По умолчанию — закрыт наглухо.

### 4.3. Пример наследования гейтов

`Феромонное излучение` (сигнатурная шкала Люциканов), хвост «глухое» заперт. Чтобы
открыть, нужен стэк по родителям, напр.: `редкая линия крови` (Биология) **И** `травма
гортани/желёз в детстве` (событие Фазы 2) **И** `сюжетная роль` — и только тогда хвост
становится доступен с малым весом. Один фактор — гейт закрыт, бросок схлопывается в норму.
Так «общество-чует-ложь-а-он-нет» не может выпасть дёшево.

### 4.4. Куда тратится бюджет глубины (до любого отклонения)

P11 на практике: сперва наполняем персонажа этим, и обычно этого достаточно —

- **Универсальное желание/боль** (любовь, зависть, горе, страх посредственности, нужда
  в одобрении родителя) — то, что есть у каждого.
- **Давление нормального мира на это чувство** (феромонный социум → приватное чувство
  публично → обычный стыд неизбежен). Глубина — отсюда, не из аномалии.
- **Плотность конкретики** — этот брат, эта Сенна, эта мастерская. Запоминается
  конкретное, а не отклоняющееся.
- **Обыденное противоречие** — верность vs тоска, а не «я тайный мутант».

**Драматичные узлы — в обыденном регистре по умолчанию:** рана мелкая бытовая;
противоречие универсальное; секрет часто открытый/бытовой или отсутствует; ложных
убеждений в листе истины — 1–2 несущих.

**Вопрос-чекпоинт оператору** (ИИ/ГМ всегда тянет к драме): *«Был бы персонаж так же
силён, будь он полностью типичным? Если да — убери отклонение.»* Ответ почти всегда «да».

### 4.5. Узлы, особо склонные к ложной драме

(жёсткий дефолт-норма, гейты строгие): осознанность, интенсивность желаний, талант,
уровень развития (у большинства — плато), глубина раны, мастерство, **любая сигнатурная
черта расы**.

### 4.6. Удача этапа (бросок, не баланс)

Удача **не выравнивается** — «баланс удачи» это миф, такого механизма нет. В начале каждого
этапа брось **куб удачи**; он задаёт соотношение благо/беда для событий и исходов ЭТОГО этапа:
- 1–2 — чёрная полоса (беды перевешивают),
- 3–4 — обычно (как ляжет),
- 5–6 — везучая полоса (блага перевешивают).

Полосы между собой **НЕ компенсируются**. Реальная неравномерность судьбы и даёт ту неровность,
которой не хватает причёсанной коэрентной биографии (и заменяет искусственный «всплеск»).

## 5. Фазы и узлы

Тип: **[бросок]** — входной (катится/гейтится/выбирается); **[вывод]** — производный.

### Фаза 1 — КОРНИ (данность, не выбирается)

| Узел | Тип | Входы | Ограничивает / выдаёт | Слот плагина |
|---|---|---|---|---|
| Раса | [бросок] | — | диапазон тела, срок жизни, базовые теги, **сигнатурная черта** (заперта от отклонений, §4.2) | `Персонажи/Расы/` |
| Место рождения | [бросок] | раса | гейтит доступные слои/среды (leads) | `Локации/`, Геополитика |
| **Возраст / когорта** | [бросок] | место | год рождения → к чему цепляются «течения эпохи» (Фаза 2) | таймлайн (`История`) |
| **Биология** (движок «тело→разум») | [бросок] | раса | модификаторы и **аффордансы** (что тело *позволяет*, по норме) вниз на темперамент и желания | раса + наследуемое |
| Темперамент | [бросок] | биология | пары-черты (Pendragon) + ядро-страх/желание (мост к §6) | абстрактный |
| Таланты и склонности | [бросок] | биология, раса | потенциал (не развитие — оно в Фазе 4) | магия/ремёсла мира |

**Узел «Биология» = ДВА слоя. Слой 1 первичен; типичная ошибка — расписать Слой 2 и
забыть Слой 1.**

**Слой 1 — био-подтип (универсальный субстрат, у любого существа; ГЛАВНЫЙ драйвер разума, P2).**
Индивидуальные шкалы по колоколу — именно они различают особей *внутри* расы (анти-«Джон»):
**возбудимость/реактивность** (импульсивность, ответ на стресс) · **конституция/болезненность**
(энергия, выносливость, склонность к хворям, модиф. срока жизни) · **интеллект/обучаемость**
(скорость, абстракция, потолок талантов) · **темп/энергия** · **эмоц. устойчивость** ·
**либидо/половой драйв** (→ эрос) · сенсорика, аппетиты, сон, болевой порог.

**Слой 2 — расовая сигнатура / ксено (вторично).** Магические таланты (врождённое),
сигнатурная черта (телепатия, спячка…), морфология, аффордансы. По умолчанию = норма расы;
отклонение — только через сигнатурный замок §4.2. **НЕ подменяет Слой 1.**

**Связи вниз (P2):** возбудимость+темп → импульсивность/напор темперамента; болезненность →
↑желания покоя/безопасности, ↓физ. амбиция, дрейф к сидячему/наблюдательному; интеллект →
скорость и потолок мастерства; либидо → салиентность эроса; эти шкалы задают и **диспозицию
вовлечённости** (P16). Воля/самоконтроль — здесь, **статичный атрибут** (P9).

### Фаза 2 — ФОРМИРУЮЩИЕ СЛОИ (прожитой прогон по возрастам)

Проходится как **lifepath вперёд по возрастным этапам** (Эриксон: какая психо-задача и
связь важны в каждом возрасте). Этапы под текущий возраст, напр.: раннее детство (0–6) ·
детство (7–12) · отрочество (13–17) · юность (18–23) · и далее до «сейчас».

**Метод (P12+P13) — на каждом этапе цикл, считая только состояние из прошлых этапов:**

Каждый шаг ниже — **вывод из названных посылок** (P14), не авторский выбор. Посылки
вспоминаются из состояния <N (биология · темперамент · ценности · опыт · окружение).

0. **Удача этапа (§4.6)** — брось куб удачи: он задаёт соотношение благо/беда для событий и
   исходов этого этапа. Между этапами НЕ выравнивай.
1. **Желания этапа** — чего хочет *в этом возрасте*; **вывод**: «из [биология/опыт/среда] →
   хочет X». Не «дети хотят дружить» (жанр), а *этот* ребёнок из *своих* посылок.
2. **Действие (агентность)** — что *делает* ради X; **вывод из ≥2 посылок** + контроль
   негативом: чего бы он **не** сделал и почему выбранное бьёт альтернативы. Если посылок
   нет — действие не происходит (или установи посылку раньше).
3. **Ответ мира (P15)** — вывод из состояния МИРА, не одноразовая преграда. Спроси:
   (а) **прецедент** — народ/институт сталкивался с этим? что знает/умеет/помнит? (почти
   всегда — да); (б) **компетентность и интересы** отвечающего лица *по его установленному
   уровню* — как поступил бы человек ЭТОГО уровня (мир не глупеет ради преграды);
   (в) перечисли **реалистичные ветви**, что даёт компетентный мир; (г) **гейт-бросок,
   сдвинутый удачей этапа (§4.6),** выбирает ветвь, с поправкой на установленные посылки
   (репутация, качество школы, настрой поселения). Покажи рассуждение.
4. **Отпечаток** — что осталось: изменённое желание, навык, рана, связь, убеждение, ресурс.
   Только это переходит на следующий этап.
5. **Эволюция желания** — утолённое гаснет/преображается; отвергнутое festering/сублимируется;
   неутолённое может тянуться дальше — **но тянущееся к взрослому обязано иметь преграду
   (см. реестр)**, иначе он бы его уже закрыл.

**Реестр преград** — бегущий список: почему каждое неутолённое желание ещё не закрыто.
Аудит в конце: взрослое желание без преграды = ошибка генерации (либо он действовал и
получил/потерял, либо впиши преграду).

**Выбор с ценой (P19).** Хотя бы на одном этапе у ключевого персонажа — прожитый ВЫБОР с
реальной ценой (а не только «случилось с ним»), иначе на выходе жертва обстоятельств.

**События этапа (4 масштаба, P16).** Помимо личных решений, проверяй события, что МОГЛИ
задеть: **глобальные** (мир — обычно нет) · **мезо** (страна — редко) · **локальные**
(поселение/школа — иногда) · **личные** (семья/близкие — часто). Для каждого: реалистичность
существования (по колоколу места/времени) → задело ли → **фильтр отпечатка по диспозиции**
(вовлечённость из био-подтипа: «лезет/сторонится») → два среза (повлияло / запомнил).

**Агентность семьи и окружения (P15 на близких).** Родительские фигуры — агенты: свои
**средства** (достаток семьи — отдельная шкала), свои **желания насчёт ребёнка** (что давят:
«учись сражаться» / прими ремесло / женись удачно), своя **способность** (оплатить/достать/
открыть двери — или нет). Их давление и ресурсы лепят путь не меньше среды.

**Решение через окружение.** Если выведенное действие = «обратиться к кому-то» — этот кто-то
разрешается как агент: **может ли** (компетентность/средства) + **захочет ли** (интересы/
отношение) → исход → **эффект на отношения** (благодарность, долг отданный/взятый, напряжение,
сближение) → реакция персонажа. Так копятся долги и связи.

**Финал прогона:** «настоящее» (Фаза 3) **считывается** из накопленных отпечатков, а не
задаётся заранее; завершается **гештальтом** (P17). Узлы ниже — срезы данных, что прогон ведёт по ходу.

| Узел | Тип | Зачем |
|---|---|---|
| Нехватки / лишения | [бросок] | у большинства — мелкие; порождают компенсаторные желания и ложные убеждения (§8) |
| Капитал | [бросок] | деньги + соц. капитал: репутация, союзники, долги, обязательства, враги |
| Окружение по мере роста | [бросок] | среда детства |

## 6. Подсистема желаний (ядро игры)

Желания **производны** от биографии (§8), не тянутся из таблицы. Палитра объектов —
лишь **вокабуляр вывода**, не ролл-таблица: *признание, близость, контроль, покой,
смысл, принадлежность, новизна, превосходство, безопасность, свобода…*

Связка желаний — это **итог прожитого прогона** (§5): то, чем закончилась эволюция
желаний по этапам. Часто в неё входит **тянущееся с детства/отрочества** желание (с
зафиксированной преградой, почему не закрыто) — это и даёт временную глубину, а не
плоский срез.

У персонажа **связка из 2–3 желаний**, одно доминирующее. Каждое — структурный объект:

| Поле | Описание |
|---|---|
| Объект | чего хочет (из вокабуляра) |
| Источник | **биология** (драйв) · **рана/нехватка** (компенсация) · **идеал/ценность** (стремление) · **заимствовано** (среда/давление) |
| Интенсивность | по колоколу; у большинства умеренная |
| Слой осознанности | принимает · осознаёт, но стыдится/отвергает · **не видит (вытеснено)** |
| Текущий оттенок | здоровое выражение ↔ искажённое — **состояние на момент среза** (не траектория) |
| Конфликт | с каким другим желанием или границей воюет |

- **Многогранность** = один объект даёт разные грани в разных контекстах и разные
  источники у разных людей. Одно слово — десятки персонажей.
- **«Куда приводит»** — это поле оттенка + конфликт; *развитие* играется ГМом (P9).
- **Рана — лишь один из источников** (не вся мотивация). Конфликт желаний между собой
  и с моральными границами = поведение под давлением.
- У обычных людей: умеренная интенсивность, низкий конфликт, желания согласованы.
  У редких «граничных»: интенсивные, конфликтующие — это редкий хвост колокола.

## 7. Подсистема знаний (двойной слой)

- **Картина мира персонажа** — что *считает* истиной: о мире, о себе, о своей области.
- **Лист истины ГМа** — на каждое убеждение тег: `истина` · `искажение` · `ложь` ·
  `слепое пятно`.

«Та самая Ложь» обобщена: вместо одной лжи — целая карта, где часть верна, часть нет.
**Осознанность = насколько персонаж видит зазор.** Связь с желаниями: ложное
убеждение о том, *что* утолит желание → гонится не за тем. **Зазор о мастерстве** —
частный случай: самооценка области vs реальный уровень (Дрейфус).

## 8. Правила деривации (Фаза 2 → Фаза 3)

Движок режима A. Базовые правила (расширяемы):

| Условие из биографии | Производит |
|---|---|
| Нехватка/лишение объекта X | компенсаторное желание X (источник=рана) + ложное убеждение про X (карта знаний, тег `искажение`) |
| Сильный биодрайв (биология) | аппетитивное желание (источник=биология) |
| Образец / ментор / кумир в среде | стремление подражать (источник=идеал) |
| Норма слоя/среды (habitus) | заимствованное желание (источник=среда), часто в слое «не вижу/не своё» |
| Травма / устойчивая угроза | аверсия (зеркало желания) |
| Достаток + слой | калибровка интенсивности амбиции (модификатор колокола) |
| Тип привязанности (из воспитания) | предпочтения в собеседниках и романтике |
| Конфликт желания с нормой эпохи/слоя | узел «соц. давление / вопреки желанию» |

## 9. Связность и точка входа

- **Частичный seed.** Можно зафиксировать часть узлов («купец из X») и достроить
  остальное непротиворечиво вниз/вверх по зависимостям.
- **Проход на связность.** После генерации — проверка синергий/конфликтов узлов;
  конфликты либо разрешаются, либо сохраняются как материал для §«противоречие».
- **Обязательное противоречие.** Минимум один внутренний разлом на персонажа.

## 10. Выходной артефакт (схема чарника) и глубина

Два слоя (P6), в стиле существующих «чарников» вольта:

- **Лицевая сторона** (мир/игроки видят): внешность, манера/голос, ремесло/быт,
  заявленные ценности и вера, видимые связи, репутация.
- **Слой ГМа**: истинные желания (источники, осознанность, оттенок), секрет, лист
  истины (ложь vs правда), скрытые связи, реальный уровень мастерства, рана,
  определяющее противоречие.

## 11. Ручка глубины

| Уровень | Объём прогона |
|---|---|
| Статист | Раса + Место + Биология(кратко) + 1 доминирующее желание + ремесло |
| НПС | + темперамент, мораль, вера, 2–3 связи, секрет, эмоц. архетип |
| Ключевой / Игрок | полный прогон всех фаз + лист истины + противоречие + сеть связей |

Прямо вытекает из P4: большинство людей и генерятся неглубоко.

## 12. Открытые вопросы

1. **Стык со статами** (`app-2-combat`: руны/добродетели/изъян): нарративный движок
   *кормит* статы (таланты/развитие → числа) или живёт параллельно? — решить отдельно.
2. **Сеть персонажей** (генерация переплетённых семей/групп с общими событиями и
   контролем рекурсии связей) — кандидат в v2.
3. **Источник случайности** при реализации (кости / ГМ-выбор / ИИ-суждение) —
   отложено до выбора формы (промпт vs софт).
4. **Размещение** этого документа: сейчас `docs/superpowers/specs/`; возможно перенос в
   вольт (напр. `Игромеханика/`) как wiki-связываемую заметку.

## 13. Вне области (сознательно НЕ делаем)

- **Динамика / движение желаний во времени** (воля-как-множитель траектории, пороги
  сдачи, последствия утоления/отказа, триггеры изменения). Это решает **ГМ вживую** по
  ходу игры на основе доп. информации и каноничных событий. Генератор даёт только
  статичный срез (P9).
