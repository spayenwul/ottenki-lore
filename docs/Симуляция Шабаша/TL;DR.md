# TL;DR — Симуляция Шабаша

> Рабочие файлы симуляции НПС Шабаша Красного Вечера: копия из временной папки, которую система чистит. Не лор: итоги лежат в [[★ Шабаш — Ночь 2. Действия каждого, план убийства Нирэн]].

## Уникальное
- `Ночь 2 ред. 5/` — пересчёт после Игры 50 (21.10.2026), четыре этапа:
  - `frame.md` — источники, публичные факты, кто что знает;
  - `s1/` — повестки и намерения 34 персонажей на вечер;
  - `s2/resolve.json` — резолвер вечера (d20), проводы Виттора, где кто на 22:00;
  - `s3/` — ночные планы от первого лица (у Нирэн `kill_plan`, у Верены `protect_plan`);
  - `s4/map.json` — карта ночи: пересечения, маршрут убийства, заходы к игрокам, ⚖️;
  - `s1.md`…`s4.md` — инструкции этапов для агентов;
  - `gen_md.py` — собирает из JSON заметку «Ночь 2».
- `engine.cjs` — движок ред. 3–4 (его входные файлы утрачены); `links.py` — проверка битых wiki-ссылок против `git HEAD`.

## Учитывать
- Пути в `s*.md` указывают на старую временную папку, их нужно поправить перед повторным прогоном.
- При первом запуске `gen_md.py` копирует текущую заметку «Ночь 2» в `night2_red4.md` и берёт из неё порядок персонажей.
