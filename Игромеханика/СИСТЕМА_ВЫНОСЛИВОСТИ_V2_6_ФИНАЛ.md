## 1. Обзор архитектуры

Система двухслойная: **оперативная выносливость** (ОВ) для боевого масштаба секунд/минут и **износ** для масштаба часов/дней.

```
                   ┌─────────────────────────────────────────┐
                   │          ПОЛНЫЙ ПУЛ (константа)         │
                   │  pool = R_pool × M × E/10               │
                   ├──────────────────┬──────────────────────┤
                   │     ИЗНОС        │   ЭФФЕКТИВНЫЙ МАКС   │
                   │  (невосстановим  │   eff_pool = pool -  │
                   │   без сна)       │   wear               │
                   │                  ├──────────┬───────────┤
                   │                  │  Пустой  │ Текущий   │
                   │                  │  буфер   │ ОВ        │
                   │                  │          │(реген↑)   │
                   └──────────────────┴──────────┴───────────┘

    Траты (удары, бег, поза):
      ├─ аэробное покрытие → бесплатно (не ест ОВ)
      └─ анаэробный остаток (net) → ест ОВ из текущего
                                   → 16% от net → износ
```

Три слоя расхода:

1. **Поза** (изометрика) — базовый MET от положения тела
2. **Кинетика** (удары, шаги, бег) — добавляется сверху
3. **Аэробное покрытие** — вычитается из суммы; остаток = анаэробный drain из пула

## 2. Пул выносливости (ОВ)

### Формула

```
pool = R_pool × M × f_pool(E)
```

Где:
- `R_pool = 1.43` кДж/кг — расовая константа (человек)
- `M` — масса тела (кг)
- `f_pool(E) = E / 10` — **линейный** множитель от Выносливости

### Свойство: линейная пропорция

E=10 → ×1, E=100 → ×10, E=1000 → ×100. Персонаж с E=200 ровно в 2 раза выносливее персонажа с E=100.

### Масса тела

```
M = (22 + 3 × min(S/100, 1)) × (H/100)²
```

Кэп на BMI при S≥100: максимум ~25 BMI → ~76.6 кг при H=175. Для сверхлюдей масса не растёт безгранично (человеческая анатомия). Другие моды массы (Alirn, Shades) — в боевой лаборатории.

### Пример: пул по E (M≈72-77 кг, H=175)

| E | Пул (ОВ) |
|---|----------|
| 10 | 98 |
| 50 | 515 |
| 100 | 1 095 |
| 200 | 2 190 |
| 500 | 5 474 |
| 1000 | 10 948 |

## 3. Аэробная система

### Аэробный порог

```
E ≤ 100:  threshold_MET = 2.0 + 7.0 × (E/100)^0.7
E > 100:  threshold_MET = 9.0 + 3.0 × ln(E/100)
```

### Аэробная мощность

```
aerobic_cap = threshold_MET × basal_rate(M)
basal_rate(M) = (M/70)^0.75 × 0.080   (ОВ/с)
```

Любая нагрузка ниже аэробного порога — **бесплатна**: организм покрывает её за счёт кислородного метаболизма, пул не расходуется.

### Аэробный порог по E

| E | Порог (MET) | Аэр. мощность (ОВ/с) |
|---|------------|----------------------|
| 10 | 3.4 | 0.267 |
| 50 | 6.3 | 0.515 |
| 100 | 9.0 | 0.770 |
| 200 | 11.1 | 0.948 |
| 500 | 13.8 | 1.183 |
| 1000 | 15.9 | 1.361 |

### Что покрывает аэробика (E=50)

## 5. Кинетические траты

### 5.1 Удары

```
E_limb = ½ × m_kinetic × v² × limb_cycle
E_body = ½ × m_body × v_body² × body_cycle
cost_OV = (E_limb + E_body) / η / 1000 × I² × D_mod
```

Где:
- `v = K × √(S/10) × D_mult` — скорость удара (м/с)
- `m_kinetic = kinetic_frac × M` — кинетическая масса конечности
- `m_body = body_engage × M` — масса тела в развороте
- `v_body = body_v_frac × v` — скорость движения тела
- `η = 0.25` — КПД мышц
- `I²` — квадратичная интенсивность
- `limb_cycle = 1.7`, `body_cycle = 2.0` — множители полного цикла (разгон + ретракция)

### Параметры ударов

| Удар | K | kinetic_frac | body_engage | body_v_frac |
|------|---|-------------|-------------|-------------|
| jab | 4.3 | 0.030 | 0.00 | 0.00 |
| cross | 4.0 | 0.057 | 0.35 | 0.20 |
| hook | 4.1 | 0.050 | 0.30 | 0.18 |
| uppercut | 3.9 | 0.047 | 0.30 | 0.15 |
| roundhouse | 4.0 | 0.100 | 0.45 | 0.20 |
| push_kick | 2.5 | 0.080 | 0.35 | 0.15 |

### Стоимость ударов (100%, S=D=E)

| E | Jab | Cross | Roundhouse | %пула/Cross |
|---|-----|-------|------------|------------|
| 10 | 0.12 | 0.26 | 0.43 | 0.27% |
| 50 | 0.65 | 1.37 | 2.26 | 0.27% |
| 100 | 1.38 | 2.92 | 4.81 | 0.27% |
| 500 | 6.88 | 14.59 | 24.06 | 0.27% |
| 1000 | 13.77 | 29.17 | 48.12 | 0.27% |

**Ключевое свойство: %пула на удар = const (0.27%) при S=D=E** на любом уровне, в любом моде массы. 375 кроссов до полного истощения всегда.

### D-модификатор (Ловкость / Сила)

```
D/S < 0.5:  D_mod = 1.0 + (0.5 - D/S) × 0.3    (штраф до 1.15)
0.5 ≤ D/S < 1.5:  D_mod = 1.0 - (D/S - 0.5) × 0.35  (бонус до 0.65)
D/S ≥ 1.5:  D_mod = 0.65                          (максимальный бонус)
```

Ловкач (D>S) — экономнее: меньше лишних движений. Силач (S>D) — расточительнее.

### 5.2 Ходьба

```
E_step = (½Mv²K_step + Mg×dh) / η / 1000 × D_mod
v_walk = 1.4 м/с (константа)
stride = 0.42 × H_m
```

Ходьба полностью аэробна для всех E ≥ 10.

### 5.3 Бег

```
v = I × v_max,   v_max = k_sprint × √(S/10) × D_mult
K_step(I) = 0.04 + 0.08 × I
dh(I) = 0.08 × (0.5 + 0.5 × I)
stride(I) = 0.75 × H_m × (0.6 + 0.4 × I)
```

Калибровка: S=100, D=100 → v_max ≈ 12.5 м/с (Болт ~12.4).

### 5.4 Боевой шаг (footwork)

```
v = 1.8 м/с (константа, не зависит от S)
stride = 0.08 × H_m
K_step = 0.12,  dh = 0.02
```

Footwork = шаффл на подушечках стоп. Стоимость ≈ 1.2× ходьбы. Не взрывное действие.

## 6. Регенерация

### Условие

Реген работает **только** когда текущий расход < аэробного покрытия (есть «запас» аэробной мощности).

### Формула

```
base = eff_pool / (T_BASE_FULL / h_regen(E))
h_regen(E) = E / 10                    — линейный, как пул
T_BASE_FULL = 3600 с                   — теоретическое время 0→100% при E=10

headroom = (aerobic - cost) / aerobic   — доля свободной аэробики
mult = 0.3 + 1.7 × headroom            — чем больше покоя, тем быстрее

fatigue = (cur / eff_pool)^0.3          — чем меньше ОВ, тем медленнее
                                          (на 10% — реген ×0.50, на 50% — ×0.81)

regen_rate = base × mult × fatigue
```

### Скорость регена по E

| E | Теор. 0→100% | 30%→90% (лёжа) |
|---|-------------|----------------|
| 10 | 60 мин | 28 мин |
| 50 | 12 мин | 5 мин |
| 100 | 6 мин | 2.4 мин |
| 500 | 72 сек | 28 сек |
| 1000 | 36 сек | 14 сек |

Сверхсущества восстанавливают оперативный пул за секунды — это **фича**: быстрый реген компенсируется **износом**, который не восстановить без сна.

## 7. Долгосрочное истощение (износ)

### Концепция

Каждая единица анаэробной траты оставляет «микроповреждения»: истощение гликогена, микротравмы мышечных волокон, нейроусталость. Износ снижает **максимальный** пул. ОВ не может подняться выше эффективного максимума.

### Накопление

```
wear += net_anaerobic_drain × K_WEAR
K_WEAR = 0.16                          — 16% анаэробной траты → износ
WEAR_CAP = 0.80                        — максимум износа = 80% пула
eff_pool = pool - wear                 — эффективный максимум
```

### Восстановление

Только в глубоком покое. Стоя, сидя, в бою — **ноль**.

| Поза | Скорость | Время 80%→0% |
|------|---------|-------------|
| sleep | 16.7% пула/ч | ~5 часов |
| lying | 8.3% пула/ч | ~10 часов |
| всё остальное | 0 | никогда |

### Один бой (1 минута, S=D=E)

| E | Пул | ОВ после | Износ | Макс |
|---|-----|---------|-------|------|
| 10 | 98 | 55 | 7 | 91 |
| 50 | 515 | 421 | 15 | 500 |
| 100 | 1095 | 955 | 28 | 1067 |

Один бой — износ незначительный: 1-7% от пула.

### 5 боёв × 2 мин (10 мин отдых сидя между)

| E | Пул | ОВ | Износ | Макс |
|---|-----|-----|-------|------|
| 10 | 98 | 2 | 65 | 33 |
| 50 | 515 | 400 | 115 | 400 |
| 100 | 1095 | 902 | 193 | 902 |
| 500 | 5474 | 4578 | 896 | 4578 |
| 1000 | 10948 | 9141 | 1808 | 9141 |

Износ ~16-17% от пула для E≥50 — самоподобие. E=10 страдает больше (66%) — он на нуле с 3-го раунда и бьётся «на износе».

### Военный день (E=50, 20 стычек × 2 мин, 22 мин марш между)

| Стычка | Время | ОВ | Износ | Макс |
|--------|-------|-----|-------|------|
| 1 | 2 мин | 371 | 23 | 492 |
| 5 | 1.5 ч | 279 | 115 | 400 |
| 10 | 3.3 ч | 164 | 230 | 285 |
| 15 | 5.2 ч | 49 | 345 | 170 |
| 17 | 5.9 ч | 3 | 391 | 124 |
| 18 | 6.3 ч | 0 | 412 | 103 |

К 18-й стычке боец **физически сломан**: пул на нуле, износ достиг кэпа (80%). Даже если он отдохнёт сидя несколько часов — ОВ восстановится до макс (103), но макс — это 20% от нормы. Нужен сон.

### Восстановление после военного дня (износ 412 из 515)

| Сон | ОВ | Износ | Макс |
|-----|-----|-------|------|
| 1 ч | 189 | 326 | 189 |
| 2 ч | 274 | 240 | 274 |
| 4 ч | 446 | 69 | 446 |
| 6 ч | 515 | 0 | 515 |

6 часов сна = полное восстановление.

### Сверхлюди: 20 боёв × 1 мин (5 мин отдых стоя)

| E | Бой | ОВ | Износ | Макс |
|---|-----|------|-------|------|
| 100 | 1 | 906 | 30 | 1064 |
| 100 | 10 | 632 | 303 | 792 |
| 100 | 20 | 329 | 606 | 488 |
| 1000 | 1 | 9207 | 287 | 10662 |
| 1000 | 10 | 6575 | 2868 | 8081 |
| 1000 | 20 | 3731 | 5735 | 5213 |

Даже «Чудовище» (E=1000) после 20 боёв теряет половину пула на износ. Мгновенный реген ОВ не спасает — фундаментальная усталость копится.

## 9. Масштабирование 100+

### Ключевое свойство: самоподобие

При S=D=E масса сокращается из всех формул:

```
Стоимость ∝ M × v² ∝ M × S
Пул ∝ M × E/10 ∝ M × S/10

Стоимость/Пул = const   ← масса нейтральна
```

Это означает:
- **%пула на удар** одинаков от E=10 до E=1500 (0.27% за cross)
- **Мод массы** (Biopunk/Alirn/Shades) не влияет на баланс — только на абсолютные числа
- **Бой 1 мин** стабилизируется на ~85% остатка для E≥100

### Масштабирование скоростей

```
v_strike = K × √(S/10)      v_run = k_sprint × √(S/10)
```

| S | Cross (м/с) | Спринт (км/ч) |
|---|------------|--------------|
| 10 | 4.3 | 14 |
| 100 | 13.6 | 45 |
| 500 | 30.4 | 101 |
| 1000 | 43.0 | 142 |

### Архетипы сверхлюдей (1 мин боя)

| Архетип | S/D/E | Пул | Остаток |
|---------|-------|-----|---------|
| Стекл.пушка | 500/500/50 | 534 | 0% |
| Сбалансированный | 500/500/500 | 5342 | 85% |
| Танк | 200/200/500 | 5168 | 96% |
| E-танк | 200/200/1000 | 10336 | 98% |
| S-пушка | 1000/1000/100 | 1095 | 0% |
| Чудовище | 1000/1000/1000 | 10948 | 85% |

Сила без выносливости = стеклянная пушка. Выносливость без силы = неутомимый, но слабый.

### Дескрипторы ситуаций

```python
# Позы
D_pose('combat_active')           # активный бой
D_pose('sitting')                  # отдых сидя
D_pose('sleep')                    # сон

# Движение
D_walk()                           # ходьба 1.4 м/с
D_run(0.50)                        # бег 50%

# Бой
D_combat(
    strikes=[('cross', 1.0, 0.85), ('hook', 0.5, 0.85)],
    footwork=3.0,                  # шагов/сек
    pose='combat_active'
)
```

### Формат вызова симуляции

```python
result = simulate(
    S=50, D=50, E=50, H=175,
    profile=[
        (0,   60, fight_descriptor),    # 0-60с: бой
        (60, 360, D_pose('sitting')),   # 60-360с: отдых
    ],
    duration=360,
    start_pct=1.0,          # начало на 100%
    start_wear=0.0,         # без износа
)
```

Возвращает:
- `pool` — полный пул
- `eff_pool` — эффективный максимум (pool - wear)
- `final_ov` — текущий ОВ
- `wear` — износ в ОВ
- `log` — покадровый лог с t, ov, eff_pool, wear, cost, net

## Известные ограничения

1. **Скорость бега**: v = k×√(S/10) → S=1000 = 142 км/ч. Для фэнтези приемлемо, для реализма нужен потолок.
2. **Пул не зависит от S/D**: дизайнерское решение — E = единственный стат выносливости.
3. **Нет деградации**: скорость удара не падает при низком ОВ. Возможно добавление I_max cap при <30%.
4. **Изометрика фиксирована**: MET позы не зависит от E (тренированный держит гард так же тяжело).
5. **Нет температурных эффектов**.
